Waypoint includes only SRD-marked core entries from the source data. The embedded JSON records the source commit and retrieval date. SRD aliases replace proprietary names where provided. Additional sourcebook material, fluff, images, and unresolved inherited records are omitted. Text is reformatted into a simplified reference view. Shared item definitions, linked rules, lair actions, and regional effects are not automatically expanded. This is a reference subset, not a full reproduction of the 5etools database or rulebooks.
